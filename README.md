asta-s.eu.scraping.kleinanzeigen.de
==========================

Install
-------

```
python -m venv /path/to/venv
source /path/to/venv/bin/activate
make update_pip_and_wheel
make install_dev # or pip install . # for prod  
```

Verify and Validate
-------------------

```
make code_check
```
